# Spring Boot MongoDB CRUD Demo

- Java 21, Spring Boot 3.5.16, Gradle, Spring Data MongoDB, MongoDB 7.0.
- Three `MongoRepository` interfaces (`OrderRepository`, `ProductRepository`, `InventoryRepository`).
- CRUD, derived queries, annotated `@Query`, dynamic filters using custom repository fragments and `MongoTemplate`.
- This is **Spring Data MongoDB**, not Spring Data JPA. There is no `spring-boot-starter-data-jpa`.

## Run

```bash
docker compose up -d mongodb
# Requires Gradle 8.14+ installed OR generate a Gradle wrapper locally first
gradle bootRun
```

If using a remote MongoDB 7.0 deployment:

```bash
export MONGODB_URI='mongodb://HOST:27017/order_management_demo'
gradle bootRun
```

If authentication is enabled, provide an appropriate authSource in your URI. Avoid committing credentials.

## Endpoints

| Entity | CRUD | Dynamic | Derived | @Query |
| --- | --- | --- | --- | --- |
| Order | `/api/orders` | `/api/orders?customerId=CUS-001&version=1&status=PAID` | `/api/orders/derived?customerId=CUS-001&status=PAID` | `/api/orders/annotated?customerId=CUS-001&version=1&status=PAID` |
| Product | `/api/products` | `/api/products?productId=P001&version=1&status=ACTIVE` | `/api/products/derived?productId=P001&status=ACTIVE` | `/api/products/annotated?productId=P001&version=1&status=ACTIVE` |
| Inventory | `/api/inventories` | `/api/inventories?productId=P001&version=1&status=AVAILABLE` | `/api/inventories/derived?productId=P001&status=AVAILABLE` | `/api/inventories/annotated?productId=P001&version=1&status=AVAILABLE` |

All collections also expose `POST /api/{entity}`, `GET /api/{entity}/{id}`, `PUT /api/{entity}/{id}`, and `DELETE /api/{entity}/{id}`. Inventory adds `GET /api/inventories/by-product/{productId}`.

Dynamic filters are optional and ANDed together; results capped at 100 for demo safety. `@Query` methods use all three parameters as required.

## Try it

```bash
curl -X POST http://localhost:8080/api/orders -H 'Content-Type: application/json' -d '{"customerId":"CUS-001","version":1,"status":"PAID","totalAmount":1250.50,"createdAt":"2026-10-24T10:00:00Z"}'
curl 'http://localhost:8080/api/orders?customerId=CUS-001&status=PAID'
curl 'http://localhost:8080/api/orders/derived?customerId=CUS-001&status=PAID'
curl 'http://localhost:8080/api/orders/annotated?customerId=CUS-001&version=1&status=PAID'
curl -X POST http://localhost:8080/api/products -H 'Content-Type: application/json' -d '{"productId":"P001","version":1,"status":"ACTIVE","name":"Laptop","price":1200.00}'
curl -X POST http://localhost:8080/api/inventories -H 'Content-Type: application/json' -d '{"productId":"P001","version":1,"status":"AVAILABLE","warehouseId":"WH01","quantity":50}'
curl 'http://localhost:8080/api/inventories/by-product/P001'
```

For update (`PUT`), send the complete JSON object and use the ID returned by POST. `DELETE` returns HTTP 204.

## Caveats

- `version` is a *business version filter*, not `@Version` optimistic locking.
- `String @Id` can be converted into BSON ObjectId for 24-hex IDs by Spring Data. The UUID IDs generated by this sample remain Strings.
- The demo uses a limit of 100 but no full pagination, auth, cross-document transactions, or concurrency-safe conditional updates. Add these for production.
- `PUT` is full replacement of mapped fields and concurrent updates may overwrite data. This is intentionally a teaching example.
- MongoDB database connection needs to be accessible; Compose binds port only on 127.0.0.1 for safer local development.
- Gradle wrapper is not included; generate with `gradle wrapper --gradle-version 8.14.3` if you have Gradle installed.
